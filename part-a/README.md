## Honesty notes

- The card sort was done by **AI-simulated participants**, each grounded in one D1B participant. It is not a sort by real people.

- The accessibility findings are from an **automated AI pre-check**. A person has not yet done the keyboard-only or screen-reader walkthroughs, so no conformance claim is made.
